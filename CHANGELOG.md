# Changelog

## v2.0 — November 2026

- Rebuilt the site with Vite, TypeScript and Tailwind CSS v4. Pages are now prerendered to static HTML at build time.
- New three-colour design system (moss, sage, white), a JR monogram and a tagline.
- Added the SCRAP-WISE thesis case study with photos of the hardware build.
- Added APM Customs Brokerage (live client website, UI/UX design).
- Added a Certificates section with five certificates and a full-screen viewer.
- Added SEO metadata, Open Graph tags, structured data (JSON-LD) and alt text on every image.
- Converted images to WebP: about 33 MB of originals now ship as 2.8 MB.
- Added automated deployment to GitHub Pages.
- Hero portrait now has slanted top and bottom edges with sage accent bands. The same slant is used on the project images.
- Added looping background animations: slowly rotating contour rings, a light pulse running down the grid lines, and a slow zoom on the APM banner photo.
- SCRAP-WISE photos are now a bento layout with captions on the images.
- APM Customs Brokerage now opens with a full-width photo banner with the title on top.
